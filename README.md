# 호가 매물대 차트

바이낸스 스팟 호가창에서 대형 주문이 쌓인 가격대(매물대)를 캔들 차트 위에 표시합니다.

- `index.html` — 차트 페이지. 열려 있는 동안 1초 단위로 매물대를 추적합니다.
- `collector/collect.mjs` — GitHub Actions가 5분마다 실행하는 수집기. `collector/symbols.json`의 코인을 기록합니다.
- 기록은 `data` 브랜치의 `<심볼>.json`에 저장되고, 페이지가 열릴 때 불러옵니다.

투자 조언이 아닙니다. 큰 주문은 체결 전에 취소될 수 있습니다.
